# Walter White | Character Tribute Website

A simple and responsive Walter White character tribute website built using **HTML, CSS, and JavaScript**.

## 🚀 Live Demo

[View Website](YOUR-GITHUB-PAGES-LINK)

## 📌 About

This project is a fan-made website inspired by the character **Walter White** from *Breaking Bad*.

The website presents his character, transformation, story, and legacy through a simple dark-themed design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- Responsive Design

## ✨ Features

- Dark-themed design
- Light/Dark theme toggle
- Responsive layout
- Navigation menu
- Walter White character section
- Story and transformation section
- Image support
- Simple animations and hover effects
- Mobile-friendly design
